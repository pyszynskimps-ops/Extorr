# ExTorrent i 1337x — APK dla Androida

Publiczne repozytorium plików instalacyjnych APK. Wydania zawierają osobne aplikacje dla Android TV (ARMv7, 32-bit) oraz telefonów i tabletów (ARM64, 64-bit).

Sprawdzone pliki instalacyjne są udostępniane w sekcji [Releases](https://github.com/pyszynskimps-ops/Extorr/releases), wraz z numerami wersji i sumami SHA-256.

To kompilacje testowe. Przy zmianie certyfikatu podpisu aktualizacja starszej wersji może zostać odrzucona przez Androida. Odinstalowanie aplikacji usuwa jej lokalne dane.
